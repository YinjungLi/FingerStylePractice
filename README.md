# 指彈練習室 🎸

一個幫你練指彈吉他的網頁工具，**手機、平板、電腦都能用**（可以「加入主畫面」當 App 用，離線也能開）。

## 功能

- **輸入歌名 → 自動產生指彈譜**
  - 內建曲庫（公有領域歌曲，含旋律）：小星星、兩隻老虎、小蜜蜂、歡樂頌、生日快樂、奇異恩典、平安夜、聖誕鈴聲、友誼萬歲、卡農、日昇之屋
  - 其他歌曲：在「設定」填入 Claude API 金鑰，AI 會查出這首歌的和弦進行，再由本機的編曲引擎編成指彈譜
  - 沒有金鑰也可以：從和弦網站或歌本把和弦貼進「手動輸入和弦」，一樣自動編成指彈譜
- **歌詞**：六線譜每小節下方顯示歌詞，播放時底部大字顯示「現在這句／下一句」。按歌曲頁的「歌詞」可以從 [LRCLIB](https://lrclib.net) 開放歌詞資料庫搜尋，系統會依原曲時間先猜好每句在第幾小節，再讓你微調（歌詞只在你搜尋時即時取得，存在你自己的瀏覽器，不會放進這個專案的程式碼）
- **六線譜（TAB）**：數字顏色代表右手手指（紅 p、綠 i、藍 m、橘 a），數字右下角的小字是左手手指，譜下方標示每個時間點的右手指法
- **怎麼按**：每個和弦的和弦圖 + 中文按法說明（哪根手指按哪條弦第幾格），還有逐小節說明哪些旋律音需要額外按壓或移把位
- **難度評估**：1～5 顆星＋等級（入門／初級／中級／中高級／高級），列出原因（速度、橫按和弦、換和弦頻率、移把位…）與練習建議
- **三種編曲難度**：簡易、標準、進階（Travis 交替低音）
- **自動移調夾**：遇到 Eb、Bb 這類難按的調，會自動建議移調夾位置，改用開放和弦指型
- **播放模擬**：用撥弦合成音色播放整首歌，指板動畫同步顯示現在要按的位置、哪條弦在響、用哪根手指撥
- **調速度**：30%～120%，從慢速開始練；可以只循環某幾個小節，並開啟「每輪自動加速 5%」
- **節拍器**：右上角隨時開關；播歌時會跟歌曲同步，也可以單獨使用（可調 BPM、拍號、點我測速）
- **預備拍**：播放前先數一小節
- **記錄我的歌曲**：自動記住你的歌、每首歌的設定、練習次數、練習時間與練到的最快速度；可匯出／匯入備份，在手機和電腦之間搬資料

電腦快捷鍵：空白鍵＝播放／暫停、↑↓＝調速度、M＝節拍器

## 怎麼開啟

這是純前端網頁，不需要安裝任何東西，但因為使用了 ES modules，需要透過網址開啟（不能直接雙擊 `index.html`）。

**在電腦上試用：**

```bash
cd FingerStylePractice
python3 -m http.server 8000
# 打開瀏覽器到 http://localhost:8000
```

**讓手機也能用（推薦：GitHub Pages，免費）：**

1. 把這個分支合併到 `main`
2. GitHub 專案頁面 → Settings → Pages → Source 選「Deploy from a branch」，Branch 選 `main`、資料夾選 `/ (root)`
3. 幾分鐘後會得到一個網址（例如 `https://<你的帳號>.github.io/FingerStylePractice/`），手機打開後選「加入主畫面」即可

> iPhone 小提醒：如果播放沒有聲音，請確認手機側邊的靜音開關沒有打開。

## 關於 AI 查歌

- 只向 AI 取得**和弦進行**（不含歌詞與旋律），指彈編排是在你的裝置上由編曲引擎產生的。所以內建曲庫以外的歌，產生的是「低音 + 分解和弦」的指彈伴奏版；內建曲庫與你自己輸入旋律的歌，則是「低音 + 旋律」的獨奏版。
- AI 查到的和弦可能和原曲有出入，可以按「編輯和弦」修改。
- API 金鑰只存在你自己瀏覽器的 localStorage 裡，不會上傳到其他地方（只會直接送到 Anthropic API）。請不要在公用電腦上儲存金鑰。金鑰可到 [console.anthropic.com](https://console.anthropic.com) 申請，每次查歌會產生少量 API 費用。

## 資料存放

歌曲與練習紀錄存在瀏覽器的 localStorage，**每台裝置各自獨立**。要在手機和電腦之間同步，請用首頁的「匯出」產生 JSON 檔，再到另一台裝置「匯入」。清除瀏覽器資料會刪掉紀錄，建議偶爾匯出備份。

## 手動輸入格式

```
[主歌] C G | Am Em | F C | Dm G |
[副歌] F G | Em Am | Dm G | C |
```

- `|` 分隔小節；一個小節兩個和弦就各彈一半，`C:3 G:1` 可指定拍數
- `[段落名稱]` 標在行首
- 旋律（選填，進階）：`C4 C4 G4 G4 | A4 A4 G4:2 |`，`:2` 兩拍、`:0.5` 半拍、`r` 休止

## 程式結構

| 檔案 | 用途 |
|---|---|
| `js/arranger.js` | 編曲引擎：選移調夾、安排低音/旋律/內聲部、左右手指法、難度評估 |
| `js/chords.js` | 和弦按法資料庫（開放和弦 + 自動計算的封閉和弦）與中文說明 |
| `js/audio.js` | Karplus-Strong 撥弦合成、精準排程、節拍器、循環與變速 |
| `js/render.js` | SVG 六線譜、和弦圖、指板動畫 |
| `js/songs.js` | 內建曲庫 |
| `js/ai.js` | 用 Claude 查詢歌曲和弦 |
| `js/lyrics.js` | 從 LRCLIB 搜尋歌詞並對齊小節 |
| `js/store.js` | 本機儲存與匯出匯入 |
| `js/app.js` | 介面邏輯 |

測試：`npm test`（需要 Node.js 18 以上）
